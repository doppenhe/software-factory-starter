# Agent Start Prompt

Use this when starting a new project from this repository:

```text
Read CODEX.md and follow the boot sequence. Ask the project intake prompts, then produce a SCOPE block and wait for confirmation before implementation.
```

Use this when resuming an existing project:

```text
Read CODEX.md and state/PROJECT_STATE.md. Tell me the current SPEAR phase, open questions, and the next action. Do not change files until you know whether we are before or after the Scope gate.
```

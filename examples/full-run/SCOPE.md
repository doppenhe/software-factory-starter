# SCOPE

## Audience

A project owner and a cold agent starting a portable software-factory project.

## Job

Create a minimal clone-ready project harness that can scope, plan, execute, assess, and hand off work.

## Success Criteria

- Project files initialize without local paths.
- The runner can print the next checklist item.
- The report contract can be validated.
- The verifier passes on a clean clone.

## Non-Goals

- No production app.
- No external service integration.
- No paid model dependency.

## Format

Repository scaffold.

## Unknowns

- Actual product domain.
- Hosting target.
- Team workflow.

Status: example

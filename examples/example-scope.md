# Example SCOPE

## Audience

A cold agent and a project owner starting a new software project.

## Job

Define enough context that the agent can plan and execute the first useful version without guessing.

## Success Criteria

- The agent knows what to build.
- The project owner has confirmed the scope.
- Non-goals are explicit.
- Unknowns are visible.
- The next step is a plan, not more discovery.

## Non-Goals

- No implementation before confirmation.
- No deployment decisions unless the owner names them as constraints.
- No speculative feature backlog.

## Format

Repository scaffold plus durable state files.

## Unknowns

- Preferred stack.
- Deployment target.
- Whether CI is required on day one.

## Confirmation

Status: confirmed

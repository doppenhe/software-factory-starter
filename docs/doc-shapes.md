# Document Shapes

BLUF: every document an agent reads should have a shape. Shape reduces ambiguity and keeps the agent from inventing structure mid-run.

## Pyramid

Use pyramid when the reader needs the answer first:

- Lead with the conclusion.
- Support with reasoning.
- Put caveats after the main claim.

Best for memos, briefings, closeouts, and status updates.

## MECE

Use MECE when partitioning a problem:

- Mutually exclusive.
- Collectively exhaustive.
- No overlap.
- No gaps.

Best for rubrics, taxonomies, feature scopes, and coverage matrices.

## Seven Circumstance

Use seven circumstance when a fact needs a complete frame:

- Who.
- What.
- When.
- Where.
- Why.
- How.
- Evidence.

Best for research notes, bug reports, audit findings, and decision records.

## Required Rule

Every doc should declare its shape or make the shape obvious from the template.
